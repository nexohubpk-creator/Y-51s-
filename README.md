# Honda 125 Launcher (vivo Y51s)

Features
- Home par DOUBLE TAP = screen lock (pehli dafa Device Admin permission allow karein)
- Lock widget (home screen par widget add karein, tap = screen lock)
- Sab app icons stylish (dark glass plate + neon ring)
- Honda 125 wallpaper (home par long press = apni photo chunein)
- Swipe up ya "APPS" button = app drawer

## APK banane ka tareeqa 1: Android Studio
1. Android Studio (Koala 2024.1 ya naya) mein "Open" -> HondaLauncher folder
2. Sync hone dein, phir Build -> Build APK(s)
3. APK: app/build/outputs/apk/debug/app-debug.apk

## Tareeqa 2: bina Android Studio (GitHub Actions)
1. github.com par naya repository banayein, is folder ki sari files upload karein
2. Actions tab -> "Build APK" -> Run workflow
3. Complete hone par "HondaLauncher-apk" artifact download karein

Phone par APK install karein, Home dabayein, "Honda 125 Launcher" -> Always chunein.
